# Python 42

This repository is a personal learning project inspired by the educational approach of 42, with a focus on understanding Python from its fundamentals.

The goal is to practice core programming concepts by rebuilding common behaviors, manipulating data structures, and creating reusable utility functions that can be used later in larger projects.

## Project purpose

This repository is designed to help develop a deeper understanding of Python by working on progressively more advanced exercises covering:

- basic syntax and program structure
- data types and conversions
- strings, lists, dictionaries, and matrices
- control flow and logic
- exception handling
- system and terminal interactions
- reusable utility design

The main idea is not simply to solve exercises, but to understand how Python behaves internally and how common tools can be recreated from first principles.
