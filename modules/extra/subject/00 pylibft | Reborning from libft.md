# pylibft | Reborning from libft

## Common Instructions
### Architeture
This project must be usable as a library in other projects. For that, you should follow a library architecture similar to this:
```txt
pylibft/
├── pyproject.toml
├── README.md
├── LICENSE
├── .gitignore
└── src/
    └── pylibft/
        ├── __init__.py
        └── assignment/
            ├── __init__.py
            └── assignment.py
```
However, you may follow a different architecture if you believe it is more appropriate for your project.

### Clean code and code quality!
Make sure to run the following commands for this project: `flake8 && mypy .`.

You should also run: ` mypy --strict .` for this project.
