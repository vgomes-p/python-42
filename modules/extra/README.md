# Extra Module - Pylibft | Reborning from libft

This project was created by me. Its purpose is to learn the fundamentals in the same spirit as the 42 libft project, but using Python.

"Why recreate functions like print or input when Python already provides them?" The answer is simple: understanding how something works is often more valuable than simply using it. In many cases, the best way to master a language is to rebuild the fundamental tools from first principles and study their behavior in depth.

This module contains recreations of core Python behaviors, as well as utility functions that may be useful in future projects. The goal is not to replace the standard library, but to develop a deeper understanding of how it works and to strengthen the foundations needed for more advanced work.

**This is not an official 42 New Core subject.**
